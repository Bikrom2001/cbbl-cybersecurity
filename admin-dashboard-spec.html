Specification

Component and behaviour notes

Access control

Four roles: administrator, admissions, instructor, content editor. Server-side authorisation on every route; no role decisions in the browser.

Table behaviour

Sortable columns, sticky header, keyboard-navigable rows, and pagination at 25 rows. Numeric columns right-aligned and tabular.

Empty and error states

Every panel specifies an empty state with a next action, and an error state with a retry. No blank white boxes.

Accessibility

Contrast at 4.5:1 minimum, visible focus rings, ARIA labels on icon buttons, and charts paired with a text summary.

Data protection

Learner records are personal data: field-level access, export logging, and retention rules applied automatically.

Performance

List endpoints paginated and indexed; dashboard aggregates cached for 60 seconds. No full-table scans in the UI.
